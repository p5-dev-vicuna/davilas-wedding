# Proposal photos

Drop the proposal photos here with **any names** — `.jpg`, `.jpeg`,
`.png`, or `.webp` all work.

- They render in filename order (numeric-aware: `photo2` before `photo10`).
- While the folder is empty, the gallery shows a small "coming soon" note
  under **The Proposal** instead.
- Publishing = commit + push; the next build re-scans this folder.
