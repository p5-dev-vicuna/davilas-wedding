# Proposal photos

Drop the proposal photos here with **any names** — `.jpg`, `.jpeg`,
`.png`, or `.webp` all work.

- They render on `/gallery/proposal` in filename order (numeric-aware:
  `photo2` before `photo10`), as lightbox tiles.
- Optional thumbnails: a same-named file in `thumb/` (e.g.
  `thumb/photo2.jpg` next to `photo2.jpg`) renders in the grid while the
  lightbox keeps the full photo. Without one, the dropped photo renders
  in the grid directly.
- While the folder is empty, the page shows a small "coming soon" note
  instead.
- Publishing = commit + push; the next build re-scans this folder.
