# AGENTS.md — start here

Rules for every AI agent (or human contributor) working in this repo:

1. **Read [`CLAUDE.md`](CLAUDE.md) first** — it is the operative agent file
   (build gates, deploy verification, repo facts, gallery workflows).
   Nothing here replaces it.
2. **Read [`BRAND.md`](BRAND.md) before any design or copy change** — see
   Design Authority below.

## Design Authority

- [`BRAND.md`](BRAND.md) is the single source of truth for visual and copy
  decisions: palette, typography, spacing, components, imagery, voice.
- Every agent must follow it for consistency across sessions and agents.
- Deviations require **owner approval, recorded in chat** before the change
  is pushed. If BRAND.md and the live site disagree, the live site wins —
  report it and fix the doc.
